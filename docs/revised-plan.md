# 현재 개발 기준

2026-10-28 기준. 현재 이후 개발·검증·배포는 승준이 혼자 이어간다.
초기 성모·승준 분담과 성모 작성 코드는 기여 기록으로 유지한다.

- [실제 PR·작성 커밋 대조](https://github.com/majung-team/majung/blob/main/docs/development-status.md)
- [현재 접속·설치·테스트](https://github.com/majung-team/majung/blob/main/docs/team-testing.md)
- [초기 기능·분담 계획](https://github.com/majung-team/majung/blob/main/docs/revised-plan.md) — 당시 계획이며 현재 할당표가 아님

일반 사용자는 차량 QR과 휴대전화 카카오 로그인으로 처음 연결한다.
관리자 일회용 등록 코드는 내부 시험·관리 절차와 구분한다. 차량 권한과 픽업 권한은 별도이며
실제 VIN·소유권 인증으로 설명하지 않는다. main 반영, 운영 배포, 시험 서버·에뮬레이터,
실제 휴대전화, 실차 결과를 각각 구분한다.
