# 개정 기획 기준

[통합 분석과 기능별 작업 순서](https://github.com/majung-team/majung/blob/chore/21-repository-split/docs/revised-plan.md)를 기준으로 본다.

이 저장소는 기존 main의 동작을 이관한다. 새 명세의 미구현 기능을 완료로 표시하지 않는다.
9.1은 최초 일회용 등록 코드 → 차량별 권한 안전 저장 → 개별 철회로 확정했다. 픽업마다 코드를 요구하는 방식과 공통 키 APK 주입은 최종 방식이 아니다.

기능 담당은 성모·승준으로 나누되, 각자 필요한 서버·차량·웹 변경을 함께 맡는다.
